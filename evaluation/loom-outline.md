# Week 4 Loom outline — 3–4 minutes

Record after live baseline and improved evaluation, using actual measured values.

1. **Use case (20 seconds):** Northstar IT; employee support with confirmed resolution or human handoff.
2. **Dataset (40 seconds):** Show 40 cases and the 50/30/15/5 scenario mix. Explain project-grounded synthetic provenance and human label review. Open one expected trajectory.
3. **Rubric (30 seconds):** Show the five metrics and numeric pass bars. Explain the difference between code assertions and human narrative review.
4. **Baseline failure (40 seconds):** Show an actual failing live case, expected versus observed output, and its failure cluster. Do not substitute scripted diagnostics for Claude results.
5. **Changes and measured results (60 seconds):** Show 3–4 implemented changes, baseline/improved metrics, identical dataset hashes, improvements and regressions.
6. **Remaining failures (30 seconds):** Explain the highest-impact unresolved issue and next step. Disclose that mocked voice API cases do not measure microphone or transcription quality.

Do not claim improvements before measuring them. Record the final workbook and relevant application/evaluation output; keep keys and private environment files off-screen.
